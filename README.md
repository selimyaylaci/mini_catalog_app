```markdown
# Mini Catalog App

## About the Project
This project is a basic-level e-commerce/catalog application developed with Flutter. It includes screens where users can list products fetched from an API, view their details, and add them to their cart using a simple state simulation. It is designed without using any external packages, strictly adhering to "Clean Code" standards and a modular folder architecture.

## Technologies Used
* **Flutter Version:** 3.41.4
* **Development Environment:** Visual Studio Code
* **Data Source:** Fake Store API

## Getting Started
To test the project on your local machine, you can follow these steps:

```


1. Clone the repository to your machine:
```bash
git clone https://github.com/selimyaylaci/mini_catalog_app.git

```


2. Navigate to the project directory:
```bash
cd mini_catalog_app

```


3. Run the application:
```bash
flutter run

```
